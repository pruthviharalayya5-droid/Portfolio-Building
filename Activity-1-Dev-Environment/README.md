# Activity 1 – Development Environment Setup

This activity covers the setup and verification of the C/C++ development environment using VS Code, GCC/MinGW, and basic programming programs.

## Files

* `setup.txt` – Development environment setup details.
* `hello.c` – Simple C program that prints Hello World.
* `add.cpp` – Simple C++ program that accepts two numbers and calculates their sum.

## C Program

### Compile

```bash
gcc hello.c -o hello
```

### Run

```bash
./hello
```

### Output

```text
Hello world
```

## C++ Program

### Compile

```bash
g++ add.cpp -o add
```

### Run

```bash
./add
```

### Example Output

```text
Enter two numbers: 2
3
Sum = 5
```
