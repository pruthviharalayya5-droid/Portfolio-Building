# Activity 2 – Development Tools

This activity demonstrates the use of Python, Java, HTML, Prettier, GitLens, and Live Share using Visual Studio Code.

## Files

- `hello.py` – Simple Python program.
- `test.java` – Java program.
- `sample.html` – HTML program.
- `prettier.html` – HTML file used for Prettier formatting.
- `Screenshots/` – Screenshots demonstrating Prettier, GitLens, and Live Share.

## Tools Used

### Python
Python program developed and executed using VS Code.

### Java
Java program developed using VS Code.

### HTML
HTML page created and edited using VS Code.

### Prettier
Prettier is used to format the HTML code automatically.

### GitLens
GitLens is used to view Git information and repository history inside VS Code.

### Live Share
Live Share is used for collaborative coding in VS Code.
